# Campaign list

One motion, one persona, this week.

Size the list to the motion: 30 seats is 30 names. One person’s outbound week is ~20. Not a TAM.

If who they sell to is already locked, start there. If it isn’t, get that sentence first.

Every why is about *their* world this week — hired, in town, the event exists — never “fits the profile.”

Name the list like a Slack channel. Save it under that name.

## Examples

- `/rebel:campaign-list Thursday dinner in Stockholm, 30 seats, CROs who'd actually come`
- `/rebel:campaign-list ABM: Nordic SaaS that hired a CMO this year`
- `/rebel:campaign-list Q4 outbound — heads of sales at Swedish manufacturers, 50–200`
